- **Email text has formatting.** A text block takes bold, italic, underline, strikethrough, links and lists,
  written right on the canvas with variables shown as named chips. It's stored as a small HTML subset that
  Signals cuts back to on every send, and text written before keeps rendering exactly as it did.
- **Emails start from a layout.** An empty email offers eleven starters, each shown as a miniature: welcome,
  announcement, promotion, newsletter, new arrivals and flash sale; abandoned cart, win-back and thank-you
  automations; and order confirmation and shipping update emails.
- **`productsBySkus` on the admin API** reads products back from the SKUs something stored, like `productsByIds`
  does for ids.
- **Four more email blocks.** Discount code (a highlighted coupon with a note and a button), Footer (your store
  details, with the unsubscribe link filled in on every marketing send), Menu links (a row of text links), and
  Image + text (a picture beside a heading, text and a button, stacking on phones).
